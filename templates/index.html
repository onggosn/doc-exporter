Ubah presentasi menjadi dokumen

Ekstrak materi slide, buat dokumen per bab dengan Bedrock, lalu tinjau dan edit HTML-nya.

1. Materi dan struktur

Mode pemetaan slide ke bab

2. Contoh gaya (opsional)

Tambahkan maksimal dua pasangan presentasi dan dokumen final. Dokumen final harus berupa teks UTF-8, misalnya .html atau .txt.

3. AWS Bedrock

Gunakan region tempat model tersedia. Jika kolom ini kosong, aplikasi menggunakan region AWS profile. Jika ID Knowledge Base diisi, aplikasi mengambil tiga hasil paling relevan. "Model ID hemat" dipakai untuk deskripsi visual slide dan klasifikasi bab mode per slide — isi dengan model lebih murah (mis. Claude Haiku) untuk menghemat biaya. Mode pemetaan batch (sekaligus semua) dan penulisan isi bab tetap memakai Model ID utama di atas karena butuh akurasi lebih tinggi. Kredensial dibaca dari AWS SDK default credential chain (environment, profile, atau IAM role).
